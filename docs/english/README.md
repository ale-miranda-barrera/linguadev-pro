# Inglés — Docs de estudio por nivel CEFR

Guía completa para hispanohablantes que quieren llegar de A2 a C1 en inglés con un método sistemático. Cada nivel tiene un doc consolidado (~55-70 KB, ~8000-10000 palabras) con gramática core, vocabulario, listening/speaking/writing patterns, errores típicos de hispanos, plan de estudio semanal, recursos externos y packs asociados de LinguaDev Pro.

## Cómo usar este doc

Cada nivel sigue la **estructura estándar de 11 secciones**:

- **§0. Antes de empezar** — diagnóstico si este es tu nivel + setup para estudiar bien.
- **§1. Descripción del nivel CEFR** — can-do statements + tiempo estimado + conexión con niveles vecinos.
- **§2. Gramática core** — 10-12 estructuras clave con regla + ejemplos con traducción + error típico hispano.
- **§3. Vocabulario core** — categorías temáticas con top palabras + collocations + false friends.
- **§4. Listening** — velocidad, tipos de audio, estrategias, recursos concretos.
- **§5. Speaking** — frases funcionales, prompts de práctica, pronunciación específica.
- **§6. Writing** — tipos de texto del nivel, estructura estándar, ejemplos completos.
- **§7. Errores típicos de hispanohablantes** — 10-20 errores con corrección concreta.
- **§8. Plan de estudio semanal** — 12-20 semanas con distribución de tiempo por día.
- **§9. Recursos externos** — podcasts, YouTubers, libros, apps, exámenes oficiales (con URLs).
- **§10. Packs de LinguaDev Pro** — lista de packs de nivel + temáticos + link al backup.

## Ruta sugerida por nivel

- **A2 → A2+:** 10-14 semanas (~90-150 h).
- **A2+ → B1:** 12-16 semanas (~150-200 h).
- **B1 → B2:** 16-20 semanas (~200-300 h).
- **B2 → B2+:** 12-16 semanas (~200-400 h — se ralentiza a este nivel).
- **B2+ → C1 (siguiente meta):** requiere ~200-400 h más, sujeto a exposure real.
